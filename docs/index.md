## 学习主线

**软件基础 → AI 辅助开发 → LLM Engineering → Tools / MCP → Agent Engineering → 模型原理 → 项目实践。**

以原课程作知识骨架，根据实际目标选择顺序。每一课保留原理、操作、问题、原因、解决方法和验证标准。课程出现一个工具，不意味着今天就要安装它。

## 如何读状态

| 标记 | 意义 |
|---|---|
| 已完成 / 已有 | 有历史反馈或可核查记录；不等于本次重新验证 |
| 进行中 | 已有内容，但仍有未完成环节 |
| 计划 | 已讨论下一步，没有执行确认 |
| 待验证 | 缺少输出或证据，需要补充 |
| 暂缓 | 后续阶段再学或再安装 |
| 当前跳过 | 不属于当前路线的必要依赖 |
